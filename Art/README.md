# Art: весь арт проекта в одном месте

Эта папка лежит **вне `Assets/`**, поэтому Unity её не импортирует. Здесь удобно смотреть арт, показывать его другим и брать отдельные куски.

> ⚠️ Игра грузит спрайты героя **не отсюда**, а из `Assets/Resources/Art/Hero` (через `Resources.Load`).
> `Art/InGame/` — это копия для просмотра. Правь героя в `Assets/Resources/Art/Hero`, а потом обнови копию (команда в разделе «Как обновить»).
> Чтобы взять в игру что-то из `Art/Concepts/`, скопируй нужные PNG в `Assets/Resources/Art/<Раздел>/`.

## Общие правила для всех спрайтов в Concepts

- **Размер — родной, 1 px картинки = 1 игровой пиксель.** Импорт как у героя: Point-фильтр, без сжатия, 16 PPU.
  Это настроит `Assets/Editor/PixelArtImporter.cs`, если положить файлы в `Assets/Resources/Art/`.
- Экран — 320×180 px. Земля во всех локациях на **y = 150** (то есть 30 px от низа).
- **Pivot — в ногах (по центру снизу)**, если в таблицах ниже не сказано другое.
- Мобы смотрят **влево**, на героя. Герой смотрит вправо.
- Стиль: тёмная обводка `#272833` вокруг каждой части, у каждого цвета 3 тона, свет сверху-слева.
  Палитра героя: лаванда `#7b7bab`, багровый `#de5050`, золото `#eed878`, лёд `#82d7f0`.
- Свечения (ореолы) сделаны полупрозрачными пикселями и уже входят в спрайт. Если вместо них будут URP 2D Light, можно перерисовать без ореолов (см. `glow()` в скрипте).

## InGame/Hero — герой (в игре)

Основа — пак **Little Fantasy - Free Knight** от **Gabry Pixel**: https://gabry-corti.itch.io/freeknight
Лицензия со страницы пака: *"You can use this asset for personal and commercial purpose."*
Указывать автора лицензия не требует, но мы указываем. О перераспространении исходных файлов лицензия ничего не говорит.

| Файлы | Что это |
|---|---|
| `knight_<анимация><кадр>.png` | обычное выражение глаз (Neutral) |
| `knight_angry_…`, `knight_narrow_…`, `knight_feral_…` | те же кадры с другим выражением глаз (`EyeMood`) |

Анимации: `idle` (4 кадра), `walk` (6), `jump` (3), `atkA` (5), `atkB` (4), `spin` (8), `dash` (2), `cry` (боевой клич, 3), `ult` (13), `hit` (3), `death` (6).
Кадр 112×64, ноги в точке x=54, на 8 px выше нижнего края. Кадры переключает `PlayerAppearance.cs`.

## Backgrounds — фоны уровней

Слои рисуются в порядке номеров, сзади вперёд. Каждый слой — полный экран 320×180, прозрачный везде, кроме неба.

| Слой | Что | Тайлится по X | Параллакс (пример) |
|---|---|---|---|
| `0_sky` | градиент, луч света, пылинки | нет, стоит за камерой | 0 (стоит на месте) |
| `1_far` / `1_back` | дальние стены, сталактиты, цепи (в 1-2 ещё плачущие лица); у босса — колоннада со знамёнами | **да** | 0.2 |
| `2_mid` | ближние скалы и потолок | **да** | 0.5 |
| `3_ground` | земля (y ≥ 150) | **да** | 1 (едет вместе с миром) |
| `ground_tile.png` | тот же кусок земли 36×30, бесшовный, для Tilemap или растягивания | **да** | — |
| `4_fg` | тёмная рамка по углам и цепь на переднем плане | нет | рамка экрана, рисуется поверх героя |
| `5_lights` | свет сцены (у босса аура трона и красная аура, в городе свет костра) | нет | поверх всего, кроме UI |

Ширина 320 и все хребты, сталактиты и цепи сделаны так, чтобы стыковаться: два одинаковых слоя рядом дают бесшовную полосу.

**Props/** (ставятся на землю, y = 150):

| Файл | Pivot |
|---|---|
| `crystal_violet_small` / `_large`, `crystal_teal_small` / `_large` | центр по X; основание кристалла на y = 16 / 22 / 18 / 22 px от **верха** картинки (ореол заходит под землю) |
| `skull_pile`, `weeping_face`, `bone_throne` | низ, центр |
| `hanging_cage` | **верх**, центр (висит с потолка, в превью x = 268, y = 0) |
| `puddle` | **верх**, центр (лежит на линии земли) |

## WorldMap — карта мира

Слои: `0_bg` (регионы: свет королевства сверху, пепельные земли, вихрь Бездны снизу), `1_fog` (туман над закрытыми регионами, полупрозрачный), `2_frame` (рамка).
Пунктир пути рисует код по точкам `path_dot_*`, по одной каждые 4 px между узлами. Позиции узлов взяты из `WorldMapData.cs`.

| Icons/ | Что |

| `node_stage_{cleared,open,locked}` | обычный уровень: золотой / светлый / серый |
| `node_skull_{…}` | уровень с мини-боссом |
| `node_boss` | уровень с боссом (корона из шипов) |
| `node_town` | город (с ореолом) |

| `tooltip_panel_9slice` | панель подсказки 9×9, края 1 px (9-slice border = 1) |

## Transitions — переход между локациями (утверждено)

Последовательность (смотри `Previews/transition.gif`):
1. Герой доходит до `stage_gate` в конце уровня (pivot ворот: x = 42, y = 66 от верха — ореол ниже земли).
2. Экран закрывается **в форме короны** вокруг героя.
3. Титульная карточка: номер красным, название в 2 раза крупнее, красная линия растёт от центра, подзаголовок. Текст проявляется в 3 шага по яркости.
4. Корона раскрывается уже на новой локации.

| Файл | Как использовать |
|---|---|
| `crown_mask.png` | белая корона 99×67 — маска (SpriteMask или шейдер). Масштаб по кадрам: 300 → 200 → 130 → 80 → 50 → 32 → 22 → 14 → 0 (размер в px «радиуса» короны; у файла радиус 48), примерно 60 мс на шаг |
| `CrownIris/iris_00..08.png` | то же самое готовыми кадрами 320×180: чёрный экран с дырой-короной в центре (160, 110). `00` — закрыто, `08` — открыто. Закрытие — в обратном порядке |
| `title_card_example.png` | как выглядит готовая карточка |
| `font_3x5.png` + `font_3x5.txt` | пиксельный шрифт 3×5: глифы через 4 px, порядок символов — в txt. W и N читаются плохо, для финального UI шрифт лучше заменить |

## Как обновить

Нужен Python 3 и Pillow (`pip install pillow`). Все генераторы лежат в `Tools/ArtGen/`.

| Скрипт | Что делает |
|---|---|
| `world.py` | **стирает и пересобирает** всё в `Art/Concepts/` |
| `eyes.py` | перекрашивает глаза рыцаря из `Tools/ArtGen/hero_src` (оригинальные кадры пака) в `Assets/Resources/Art/Hero` |
| `styles.py`, `mobs.py` | старые эксперименты, результат пишут в `Docs/Concepts` |
| `pixel.py`, `shade.py` | общие хелперы |

```powershell
python Tools/ArtGen/world.py
```

После изменений героя обнови копию:

```powershell
Copy-Item Assets/Resources/Art/Hero/*.png Art/InGame/Hero/ -Force
```
