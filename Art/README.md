# Art: весь арт проекта в одном месте

Эта папка лежит **вне `Assets/`**, поэтому Unity её не импортирует. Здесь удобно смотреть арт и показывать его другим.

> ⚠️ **Игра грузит арт из `Assets/Resources/Art/`**, это и есть настоящие файлы. `Art/InGame/` — их копия для просмотра:
> она пересобирается скриптом `sync_art.py`, поэтому руками в ней ничего не правь.

## Структура

```
Art/
├── README.md
├── Previews/                      собранные картинки ×4: сцены, лист мобов, gif перехода (только посмотреть)
└── InGame/                        копия Assets/Resources/Art без .meta
    ├── Hero/                      герой, по папке на анимацию
    │   └── <анимация>/
    │       ├── preview.gif        все 4 выражения глаз рядом, ×3
    │       ├── neutral/  angry/  narrow/  feral/    кадры knight_*.png
    ├── Backgrounds/
    │   ├── 1-1_PitOfExiles/       слои параллакса и тайл земли
    │   ├── 1-2_WeepingHollows/
    │   ├── 1-5_BossArena/         колоннада, земля и свет арены (используется в конце каждого уровня)
    │   └── Props/                 кристаллы, кости, клетка, лужа, лицо в стене, трон
    ├── Mobs/                      по одному спрайту на моба
    ├── Town/                      слои Lastlight
    │   └── Objects/               дома, кузница, костёр (3 кадра), фонари, NPC
    ├── WorldMap/                  слои карты
    │   └── Icons/                 узлы по состояниям, маркер героя, точки пути, панель
    └── Transitions/               врата, маска-корона, кадры ирис-перехода, титульная карточка, шрифт
        └── CrownIris/
```

## Что где используется в игре

| Арт | Где в игре | Код |
|---|---|---|
| `Hero/` | герой во всех сценах | `PlayerAppearance.cs` |
| `Backgrounds/<уровень>/` | фон уровня: небо, дальний и средний план (параллакс), земля, рамка | `StageTheme.cs` (какой уровень чем оформлен), `PrototypeBootstrap.cs` |
| `Backgrounds/1-5_BossArena/` + `Props/bone_throne` | последние 2 экрана каждого уровня, где бой с боссом | `PrototypeBootstrap.BuildBossArena` |
| `Backgrounds/Props/` | случайно расставлены вдоль дороги | `PrototypeBootstrap.BuildRoadProps` |
| `Mobs/` | враги. 1-1: ползун, имп, гуль, огонёк + громила; босс — Тюремщик. 1-2: страж, огонёк, гуль + громила; босс — Безглазый Владыка | `StageTheme.cs`, `Enemy.Create` |
| `Town/` | город Lastlight | `TownBootstrap.cs` |
| `WorldMap/` | карта мира | `WorldMapBootstrap.cs` |
| `Transitions/` | переход между всеми сценами; врата — выход с уровня после победы над боссом | `SceneTransition.cs`, `PixelText.cs` |
| `Backgrounds/1-1_PitOfExiles/` | ещё и фон главного меню | `MainMenuBootstrap.cs` |

> **Временно:** уровень 1-2 открыт для игры, а его босс — Безглазый Владыка (по лору он босс 1-5).
> Так всё нарисованное уже можно увидеть в игре. Когда появится 1-5, поменяй босса 1-2 в `StageTheme.cs`.

## Общие правила

- **1 px картинки = 1 игровой пиксель, 16 px = 1 юнит.** Камера показывает ровно экран арта 320×180 (orthographic size 5.625), строка земли арта совпадает с `Arena.GroundY` (константы — в `ArtKit.cs`).
- Импорт настраивает `Assets/Editor/PixelArtImporter.cs`: Point-фильтр, без сжатия, 16 PPU. **Pivot — по центру снизу** (у героя — свой). Другие точки привязки задаются в коде, в пикселях от левого верхнего угла (`ArtKit.Place`).
- Земля во всех локациях на y = 150 px (30 px от низа экрана).
- Мобы нарисованы смотрящими **влево**; в игре они разворачиваются к герою сами.
- Стиль: тёмная обводка `#272833` вокруг каждой части, у каждого цвета 3 тона, свет сверху-слева.
  Палитра героя: лаванда `#7b7bab`, багровый `#de5050`, золото `#eed878`, лёд `#82d7f0`.
- Свечения (ореолы) нарисованы полупрозрачными пикселями и уже входят в спрайты.

## Hero — герой

Основа — пак **Little Fantasy - Free Knight** от **Gabry Pixel**: https://gabry-corti.itch.io/freeknight
Лицензия со страницы пака: *"You can use this asset for personal and commercial purpose."*
Указывать автора лицензия не требует, но мы указываем. О перераспространении исходных файлов лицензия ничего не говорит.

Анимации: `idle` (4 кадра), `walk` (6), `jump` (3), `atkA` (5), `atkB` (4), `spin` (8), `dash` (2), `cry` (боевой клич, 3), `ult` (13), `hit` (3), `death` (6).
Выражения глаз: `neutral` (`knight_<кадр>`), `angry`, `narrow`, `feral` (`knight_<выражение>_<кадр>`). Переключаются через `PlayerAppearance.SetEyes(EyeMood)`.
Кадр 112×64, ноги в точке x = 54, на 8 px выше нижнего края.

## WorldMap — карта мира

Слои рисуются в UI в 6 раз крупнее (1920×1080): `0_bg`, `1_fog` (пока закрыт 2-1), `2_frame`.
Пунктир дороги — точки `path_dot_*` через каждые 4 px; золотой, если следующий узел открыт.
Иконки: `node_stage_{cleared,open,locked}`, `node_skull_*` (1-4), `node_boss` (1-5), `node_town`, `node_castle`, `hero_marker` (pivot — нижний кончик), `tooltip_panel_9slice` (9×9, border 1).
Подписи узлов выводятся пиксельным шрифтом.

## Transitions — переход между сценами

`SceneTransition.Load(...)` вместо `SceneManager.LoadScene`:
1. Экран закрывается **в форме короны**: кадры `CrownIris/iris_08 → iris_00`, по 60 мс.
2. Если у перехода есть заголовок, показывается титульная карточка: номер красным, название в 2 раза крупнее, красная линия растёт, затем подзаголовок. Например, при входе на уровень или в город.
3. Загружается сцена, корона раскрывается: `iris_00 → iris_08`.

`stage_gate` — выход с уровня: появляется в конце арены после победы над боссом; если в него войти, герой уходит в город или на карту.
`font_3x5.png` + `font_3x5.txt` — пиксельный шрифт (порядок глифов — в txt). W и N читаются плохо, для финального UI его лучше заменить.
`crown_mask.png` и `title_card_example.png` — для справки и для будущего шейдерного варианта.

## Как обновить

Нужен Python 3 и Pillow (`pip install pillow`). Скрипты — в `Tools/ArtGen/`.

| Скрипт | Что делает |
|---|---|
| `world.py` | перерисовывает фоны, мобов, город, карту и переход в `Assets/Resources/Art/` (файлы перезаписываются, .meta остаются) и превью в `Art/Previews/` |
| `eyes.py` | перекрашивает глаза рыцаря из `Tools/ArtGen/hero_src` (оригинальные кадры пака) в `Assets/Resources/Art/Hero` |
| `sync_art.py` | пересобирает `Art/InGame/` из `Assets/Resources/Art/` (герой — по папкам анимаций, с gif) |
| `styles.py`, `mobs.py` | старые эксперименты, результат пишут в `Docs/Concepts` |
| `pixel.py`, `shade.py` | общие хелперы |

После любого изменения арта:

```powershell
python Tools/ArtGen/world.py
```

```powershell
python Tools/ArtGen/sync_art.py
```
