# Art: весь арт проекта в одном месте

Эта папка лежит **вне `Assets/`**, поэтому Unity её не импортирует. Здесь удобно смотреть арт, показывать его другим и держать концепты.

> ⚠️ Игра грузит спрайты **не отсюда**, а из `Assets/Resources/Art/Hero` (через `Resources.Load`).
> `Art/InGame/` — это копия для просмотра. Если правишь спрайт героя, правь его в `Assets/Resources/Art/Hero`
> (или перегенерируй скриптом), а потом обнови копию командой из раздела «Как обновить».

## Структура

```
Art/
├── README.md
├── InGame/
│   └── Hero/              копия спрайтов героя, которые сейчас в игре
└── Concepts/              превью, в игру пока не добавлены
    ├── Backgrounds/       фоны локаций, город, карта мира
    ├── Transitions/       переход между локациями
    └── Mobs/              бестиарий (в игру пока НЕ добавляем)
```

## InGame/Hero — герой (в игре)

Основа — пак **Little Fantasy Free Knight** (автор Gabry Pixel). Лицензия и источник описаны в `Docs/ThirdParty/LittleFantasyFreeKnight/SOURCE.md`.
Глаза перекрашены в наш стиль: дальний глаз ледяной голубой, ближний багровый.

| Файлы | Что это |
|---|---|
| `knight_<анимация><кадр>.png` | обычное выражение глаз (Neutral) |
| `knight_angry_…`, `knight_narrow_…`, `knight_feral_…` | те же кадры с другим выражением глаз (`EyeMood`) |
| `body_*`, `front_*`, `hair_*` | старый процедурный «бумажный» герой из `hero.py`, сейчас не используется |

Анимации: `idle` (4 кадра), `walk` (6), `jump` (3), `atkA` (5), `atkB` (4), `spin` (8), `dash` (2), `cry` (боевой клич, 3), `ult` (13), `hit` (3), `death` (6).

Технические параметры:
- кадр 112×64, ноги в точке x=54, на 8 px выше нижнего края;
- импорт настраивает `Assets/Editor/PixelArtImporter.cs`: Point-фильтр, 16 PPU, pivot в ногах;
- в игре кадры переключает `PlayerAppearance.cs`, выражение глаз меняет `PlayerAppearance.SetEyes(EyeMood)`.

## Concepts — превью (в стиле героя)

Правила стиля, по которым всё нарисовано:
- маленький «чиби» масштаб (герой ростом около 27 px);
- тёмная обводка `#272833` вокруг **каждой** части спрайта, в том числе внутри фигуры;
- у каждого цвета 3 тона, свет падает сверху-слева;
- палитра героя: лаванда `#7b7bab`, багровый `#de5050`, золото `#eed878`, лёд `#82d7f0`;
- мобы смотрят **влево**, на героя;
- картинки сохранены в масштабе ×4, родное разрешение кадра 320×180.

### Backgrounds (утверждено как направление)
| Файл | Что |
|---|---|
| `stage_1-1.png` | 1-1 Pit of Exiles: многослойный параллакс (небо, луч света из ямы, дальние стены, сталактиты, цепи, клетка, кристаллы), с макетом HUD |
| `stage_1-2.png` | 1-2 Weeping Hollows: тот же набор элементов в бирюзовой палитре, плюс плачущие лица в стене и лужи |
| `boss_arena.png` | 1-5 Throne of the Eyeless: тронный зал, трон из костей, полоса HP босса |
| `town.png` | Lastlight: город-убежище в пещере, костёр, кузница, гирлянды фонарей, NPC (кузнец, торговец, старейшина) |

Каждый новый фон делается из общего набора элементов (`cave_backdrop` в скрипте): для новой локации достаточно новой палитры и пары своих деталей.

### Transitions (утверждено)
`transition.gif`: герой входит во врата, экран закрывается **в форме короны** вокруг героя, появляется
титульная карточка «1-2 WEEPING HOLLOWS», затем корона раскрывается уже на новой локации.
В `transition_keys.png` собраны 4 ключевых кадра.

### Mobs (пока НЕ добавляем в игру)
`mobs.png`: Hollow Crawler, Despair Wisp, Gloomling (лёгкие), Chainbound Ghoul, Weeping Sentinel (средние),
Abyssal Hulk (тяжёлый), The Jailer (мини-босс 1-4), Eyeless Sovereign (босс 1-5). Рыцарь добавлен для сравнения масштаба.
Старые плоские концепты мобов лежат в `Docs/Concepts/mobs/`.

## Как обновить

Нужен Python 3 и Pillow (`pip install pillow`). Все генераторы лежат в `Tools/ArtGen/`.

| Скрипт | Что делает |
|---|---|
| `world.py` | перерисовывает всё в `Art/Concepts/` |
| `eyes.py` | перекрашивает глаза из `Tools/ArtGen/hero_src` в `Assets/Resources/Art/Hero` |
| `hero.py`, `styles.py`, `mobs.py` | старые эксперименты, результат пишут в `Docs/Concepts` |
| `pixel.py`, `shade.py` | общие хелперы |

```powershell
python Tools/ArtGen/world.py
```

После изменений спрайтов героя обнови копию в `Art/InGame/Hero`:

```powershell
Copy-Item Assets/Resources/Art/Hero/*.png Art/InGame/Hero/ -Force
```

## Что дальше
- Нарезать фоны на отдельные слои параллакса (для `ParallaxLayer.cs`) и перенести их в `Assets/Resources/Art/`.
- Реализовать переход с короной (маска плюс титульная карточка) для смены сцен.
- Поменять пиксельный шрифт 3×5: W и N в нём плохо читаются.
